# Speeding Up MATLAB

This material on speeding up MATLAB was from a presentation and practicum led by Heather Wellman and Asawari Samant at the Computational Biology Summer School at the Cold Spring Harbor Laboratory in 2009.

## Main Materials

- `SpeedingUpMatlabSlides.pdf`
- `SpeedingUpMatlab/Demos/Ex1`
- `SpeedingUpMatlab/Demos/Ex2`

## What It Demonstrates

- vectorization and logical indexing
- row-versus-column memory behavior
- block averaging examples
- simple timing and fitting examples, including `parfor`

## Best For

Students who already know basic MATLAB syntax and want examples of faster array-oriented code.
