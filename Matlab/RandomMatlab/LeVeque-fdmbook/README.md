# LeVeque Finite-Difference Reference Material

This folder contains historical public reference material related to Randall J.
LeVeque's finite-difference methods text.

Local third-party PDFs from this folder have been moved to the private
`computational-biology-lab-private` reference library. For public use, prefer the
official book and author pages linked from the historical HTML files in this
folder.

The remaining MATLAB and LaTeX source files are useful examples for students
studying finite-difference methods, but this folder should be treated as a
reference shelf rather than a polished tutorial.
