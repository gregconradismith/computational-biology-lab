# Getting Started

This repository is a teaching library. It contains examples, notes, figures, and workflows that students can study, run, adapt, and extend for research projects.

## Before Running Code

1. Confirm which folder your mentor or project is pointing you toward.
2. Read the nearest `README.md`.
3. Identify the main script, notebook, or document.
4. Run the example once without changes.
5. Change one thing at a time and record what happened.

## Keep A Useful Lab Notebook

Your notebook should make your work reproducible. For computational work, include:

- date and project context
- file names and paths
- commands you ran
- parameter values you changed
- plots or output files you generated
- mistakes, error messages, and how you fixed them
- questions for the next meeting

Use the [student checklists]({{ '/student-checklists/' | relative_url }}) when you are starting a new example, preparing for a meeting, or cleaning up work before sharing it.

## First MATLAB Path

The MATLAB README recommends this order:

1. `Matlab/NumerialIntegrationOfScalarODE`
2. `Matlab/VariableNumberOfInputArguments`
3. `Matlab/PlottingSubplotsAndMultipleYAxes`

The first folder name is misspelled as `NumerialIntegrationOfScalarODE` in the repository. Use the existing spelling so links and paths continue to work.

## Asking For Help

Ask the most junior lab member who might know the answer, then work upward as needed. Bring your notebook, the exact command or file you used, and the error message or plot that surprised you.
